# dioxus-storybook-macro

Proc macros for [`dioxus-storybook`](https://crates.io/crates/dioxus-storybook):
`#[story]`, `story_meta!`, `#[derive(Controls)]` and `#[derive(ControlEnum)]`.

The generated code refers to `::dioxus_storybook`, so depend on the facade crate
rather than on this one directly.
