# dioxus-storybook-core

Framework-agnostic core of [`dioxus-storybook`](https://crates.io/crates/dioxus-storybook):
`StoryDef`, `Meta`, the arg vocabulary (`ArgType` / `ArgValue` / `ArgMap`), the
sidebar index, URL state encoding, and the `Channel` trait that connects the
manager to the preview.

You normally depend on `dioxus-storybook` instead of this crate directly.
